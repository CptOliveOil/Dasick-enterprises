# Command Centre Vault

This folder is an [Obsidian](https://obsidian.md) vault: the permanent
engineering knowledge base for Command Centre.

## Opening it

1. Install Obsidian
2. **Open folder as vault** → select this `vault/` folder
3. Install [[Plugins|Dataview]] — every index page uses it
4. Start at [[Home]]

## Structure

| Folder | Contains |
| --- | --- |
| `00 Dashboard` | Home, maps, conventions, workflow |
| `01 Architecture` | Every system |
| `02 Businesses` | What the workforce works on |
| `03 Agents` | Who does what |
| `04 Providers` | External services |
| `05 Database` | Every table |
| `06 Workflows` | Pipelines and diagrams |
| `07 Bugs` | Permanent record — never deleted |

| `15 Templates` | Start here when writing |
