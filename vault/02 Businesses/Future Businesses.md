# Future Businesses

> [!info] Goals
> Show what has to be written, and what is already there, when adding a business.

## Agents

Register agents with capabilities. Nothing else.

## Capabilities

Add handlers to the capability registry. They run through the same [[Agent Engine]].

## Workflows

Add a workflow definition. It gets the same [[Mission Engine]], approvals and retries.

## Metrics

Whatever the business measures. [[Business Memory]] stores it per business automatically.

## Business Memory

n/a

## Roadmap

Automatic. The brief is injected into every prompt by `baseContext` — including capabilities not yet written.
