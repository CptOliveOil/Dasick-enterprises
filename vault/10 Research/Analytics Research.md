# Analytics Research

| Metric | Available | Notes |
| --- | --- | --- |
| Views | ✅ | Per day, per video |
| Estimated minutes watched | ✅ | |
| Average view duration | ✅ | |
| Likes, comments, shares | ✅ | |
| Subscribers gained | ✅ | |
| Impressions and CTR | ⚠️ | Different report, extra scope |
| Revenue | ⚠️ | Needs monetisation and a separate scope |

**We request only the first group.** Revenue and impressions are deliberately not
requested, because zero would be stored as a measurement. See
[[Never Invent Metrics]].
