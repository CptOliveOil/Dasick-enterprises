# Long Term Vision

> [!quote] The shape of the thing
> An AI workforce that runs several businesses, learns from what it publishes,
> and asks a person only where judgement is genuinely required.

## What has to stay true

1. **One engine.** Hundreds of agent types must not mean hundreds of code paths. See [[One Engine Not Two]].
2. **One workflow per job.** Demo and production must never diverge. See [[One Workflow Not Two]].
3. **Nothing invented.** Unknown stays unknown, in memory and in reports. See [[Never Invent Metrics]].
4. **Nothing approved blind.** See [[Every Approval Must Show The Work]].
5. **Nothing legally guaranteed.** See [[Never Claim Legal Safety]].

## What scale looks like

- Several businesses, each with its own memory, budget and workforce
- Providers swapped without workflow changes
- New agents added as rows plus a capability handler
- This vault as the reasoning behind all of it
